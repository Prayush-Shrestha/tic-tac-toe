# Tic-Tac-Toe

A simple and interactive Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Overview

This project is a browser-based Tic-Tac-Toe game where two players can play against each other on the same device.

The game provides a simple interface, detects winning combinations, handles draws, and allows players to start a new game.

## Features

* Two-player gameplay
* Interactive 3×3 game board
* Player turn management
* Automatic win detection
* Draw detection
* Game reset functionality
* Responsive design
* Clean and simple user interface
* Runs directly in the browser

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Event Handling

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Prayush-Shrestha/tic-tac-toe.git
```

### 2. Open the project

```bash
cd tic-tac-toe
```

### 3. Run the game

Open `index.html` in your web browser.

You can also use the **Live Server** extension in VS Code for a better development experience.

## How to Play

1. Player X starts the game.
2. Players take turns selecting an empty square.
3. The first player to get three matching symbols in a row wins.
4. The three symbols can be:

   * Horizontally
   * Vertically
   * Diagonally
5. If all squares are filled without a winner, the game ends in a draw.
6. Reset the game to play again.

## Winning Conditions

There are eight possible winning combinations:

```text
[0, 1, 2]
[3, 4, 5]
[6, 7, 8]

[0, 3, 6]
[1, 4, 7]
[2, 5, 8]

[0, 4, 8]
[2, 4, 6]
```
